# 工具路径与命令边界

## 当前问题

文件工具限制在工作区内，但 `run_command` 使用 shell 执行命令，命令可能访问工作区之外的文件

## 已完成

- 文件工具默认拒绝工作区外路径
- `run_command` 每次展示完整命令并要求单次确认
- 命令工具不允许获得 Session 级授权

## 待完成事项

- 评估工作区外路径授权是否具有真实需求
- 评估操作系统级沙箱或受限子进程方案
- 记录网络访问、环境变量和子进程权限边界

## 当前约束

- 文件工具默认拒绝工作区外路径
- `run_command` 当前只保证工作目录为工作区
- `run_command` 不是文件系统、网络或资源沙箱
