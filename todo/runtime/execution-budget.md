# Turn 预算与并行工具

## 当前边界

工具调用按模型返回顺序串行执行，避免写操作竞态、保证结果顺序稳定、简化取消与 TUI 展示。Turn 只有单请求超时和 `max_tool_rounds` 上限，没有总时长、总 Token 或总成本硬预算。

## 何时处理

满足任一条件后再立项：

- 确认只读工具并行执行安全
- 出现失控循环需要 Turn 级软限制
- 实际 usage 观测数据支持按总 Token、总时长设预算

## 唯一方向

先基于服务端 usage 增加 Turn 级总 Token、总时长观测，再决定是否增加硬上限；在此之前保持串行工具执行。

## 非目标

- 不在有观测数据前臆造 Turn 预算阈值
- 不并行执行写操作或未确认只读安全的工具
