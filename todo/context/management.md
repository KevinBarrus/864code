# 上下文管理

## 下一步目标

将完整 Session 历史转换为适合当前模型请求的上下文，避免工具结果和历史消息无限增长

## 最小实现顺序

1. 区分持久化历史、运行时记忆和模型请求上下文
2. 新增独立的 Context Manager
3. 为模型请求设置简单的消息数量或字符预算
4. 优先保留系统消息、最近用户消息和最近模型回复
5. 对超出预算的旧消息进行最小裁剪
6. 对工具结果保留完整历史，但为模型上下文预留结果截断接口
7. 增加上下文裁剪前后的单元测试

## 暂不实现

- 向量数据库
- 语义检索
- 自动摘要
- 复杂 Token 预测
- 动态控制器

## 验收标准

- Session 历史不会被直接修改
- 模型请求可以获得独立的上下文消息列表
- 超出预算时能够稳定裁剪
- 未超出预算时上下文内容保持完整
