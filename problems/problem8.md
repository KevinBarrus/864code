# 问题 8：UI 交互细节（补全、选择器、状态栏、英文化）

## 发现来源

用户实际运行 epsilon TUI 后反馈的 7 个交互问题，并参考 Codex 源码（`projects/codex/codex-rs/tui/`）的补全、选择器与状态栏实现后对齐需求。

## 总体判断

epsilon 的 TUI 在真实使用中暴露出一批交互与显示问题：补全菜单覆盖状态栏、`/mod` 按 Enter 报未知命令、补全在删字符后失效、选择器选中项颜色不清晰、切换模型后状态栏与提示不更新、余额不可查询、界面大量中文。全部按用户确认的方案修复。

## 问题清单

1. **补全菜单覆盖状态栏**：输入 `/` 后补全浮层盖住最底部状态栏。对齐 Codex 方案：补全展开时隐藏状态栏（popup 与状态栏共用空间），收起后恢复。
2. **`/mod` 按 Enter 报「未知命令」**：Enter 直接提交原文本，registry 找不到 `/mod`。对齐 Codex：补全打开且有选中项（默认第一项）时，Enter 应用选中项并提交。
3. **`/mo` 删字符后补全失效**：前缀匹配应持续有效；并对齐 Codex 增加 exact 匹配优先排序。
4. **选中项颜色不清晰**：对齐 Codex：选中项整行亮青色（`ansibrightcyan`），未选中默认色。
5. **切换模型消息**：状态栏右侧显示中文「已切换到模型：X」。改为对话区英文 tool 消息。
6. **状态栏模型名不更新 + 余额不可查询**：`StatusInfo` 冻结导致切换模型后状态栏仍显示旧模型名；余额恒为「暂不可查询」。改为状态栏动态读取当前运行时配置；实现 DeepSeek `/user/balance` 真实查询，失败降级。
7. **全英文化**：状态栏、未知命令、当前配置、已切换等所有用户可见文本改英文，代码注释保持中文。

## 附加对齐（用户确认）

- **Tab 补全但不执行**：与 Codex 对齐。
- **选择器滚动 wrap 循环**：与 Codex 对齐，覆盖此前「停在最后」的要求。

## 现有代码缺口

- `screen.py`：补全浮层覆盖状态栏；submit 绑定直接提交原文本；状态栏中文且 `StatusInfo` 冻结。
- `choice_picker.py`：光标滚动停在边界（需改 wrap 循环）；`skill_picker.py` 同。
- `commands/model.py`：切换模型消息中文且走状态栏。
- `balance.py`：只有 `UnavailableBalanceProvider`，无真实查询。
- `theme.py`：选中色为金色（需改亮青）。
- `ui.py` / `main.py` / `setup.py` / `commands/*.py`：大量中文提示。

## 验收前提

- 补全展开时状态栏隐藏，收起后恢复
- `/mod` 按 Enter 直接执行 `/model`；Tab 补全但不执行
- `/mo` 前缀匹配持续有效，exact 匹配优先
- 选中项亮青色，未选中默认色
- 切换模型后对话区显示英文提示、状态栏模型名同步更新
- 余额真实查询成功显示余额，失败降级
- 所有用户可见文本为英文
