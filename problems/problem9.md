# 问题 9：模型自我介绍与补全列表重构

## 发现来源

用户实际使用 TUI 后反馈：模型无法自我介绍（自称 Coding Agent 而非模型名）、补全列表样式与位置不符合 Codex 风格、选择器带圆圈标记、余额每轮不刷新。参考 Codex 源码（`codex-rs/tui/src/bottom_pane/chat_composer.rs` 布局与 `selection_list.rs` 样式）后对齐。

## 总体判断

- 系统提示词限定了模型身份，导致模型无法按自身认知自我介绍
- 补全列表用浮层覆盖 + 表格样式，位置在输入栏上方，与 Codex 的「布局式列表在输入栏下方」不一致
- 选择器选项带 ●○ 圆圈，Codex 用 › 前缀
- 余额只在启动时查询，每轮对话后不刷新

## 问题清单

1. **模型自我介绍**：`agent.md` 第一行宣称「你是一个面向当前工作区的 Coding Agent」，模型只能自称 Coding Agent，无法按自身训练认知回答模型名。
2. **补全列表位置**：输入栏在屏幕底部时，浮层列表显示在 `/` 上方，不符合 Codex 的「列表在输入栏下方」。
3. **补全列表形式**：浮层呈现为表格样式，应改为单选列表（命令名 + 描述），选中项亮青色。
4. **补全列表选中色**：选中项为难以分辨的浅灰/深灰，应改为亮青（与 select model 一致）。
5. **选择器圆圈**：选项前带 ●○ 标记，应去掉，选中用 › 前缀。
6. **余额不刷新**：余额只在启动时查询一次，每轮对话后不更新。

## 设计决策（来自讨论的取舍）

1. **去掉身份宣称**：删除 `agent.md` 第一行身份句，保留 5 条行为规则；不注入模型名，模型用自身认知回答（换模型自然切换，不会露馅）。
2. **布局式补全列表**：底部区域 = 状态栏或补全列表二选一；输入 `/` 时替换状态栏为列表，对话区被挤占，列表始终在输入栏下方；删除 `/` 后输入栏位置不变。
3. **CommandPicker**：自建单选列表控件（命令名 + 描述），选中项亮青、未选中默认色，选中前缀 `›`；`↑/↓` 选择、滚动跟随；Enter 应用并提交、Tab 应用不提交；监听 `buffer.on_completions_changed` 实时渲染。
4. **选择器去圆圈**：ChoicePicker 去掉 ●○，选中行用 `›` 前缀。
5. **余额每轮刷新**：每轮对话结束后异步重新查询余额并更新状态栏（余额动态 provider），刷新失败保留旧值。
6. **移除 CompletionsMenu 浮层**。

## 现有代码缺口

- `src/core/prompts/agent.md`：身份宣称限定了模型认知
- `screen.py`：CompletionsMenu 浮层 + 状态栏 ConditionalContainer 隐藏方案
- `choice_picker.py`：●○ 圆圈标记
- `ui.py` / `main.py`：余额只在启动时查询，未传入 TUI

## 验收前提

- 问模型「你是什么模型」时，模型按自身认知回答，不宣称 Coding Agent 身份
- 输入 `/` 后补全列表在输入栏下方（布局式），对话区被挤占，状态栏被替换
- 补全列表单选样式，选中项亮青 `›` 前缀，未选中默认色
- 选择器选项无圆圈，选中 `›` 前缀
- 每轮对话后余额刷新，失败保留旧值
